Mission documentation · Rev 0

Evidence-based multi-agent orchestration

Sagan

Extraordinary claims require extraordinary evidence.

One accountable PM agent dispatches stateless specialist workers — frontend, backend, research — against tickets whose acceptance criteria are written before any work starts. Nothing user-visible ships without a fresh critic’s verdict and a non-builder verifier recording commands, exit codes, and screenshots at a git SHA. It installs as a self-contained .sagan/ directory; humans stay in the loop at per-ticket promote gates.

Approved = verified — not plausible

1.1 The rules

  • AC before dispatch Critic without AC is opinion; critic against AC is a contract.
  • Flags, never fixes The critic judges; the builder fixes; nobody self-approves.
  • Builder ≠ verifier Structural, not cultural — the verifier is never the builder.
  • Reading is not judging NEEDS_EVIDENCE exists so render and runtime claims require execution output.
  • Approved = verified Ship requires critic approval and non-builder evidence at a git SHA.
  • Caps are circuit breakers Round limits escalate to a human, never silent approval.
  • Decisions surface structurally Open decisions arrive as batched questions with recommended defaults — never buried in prose.

Section 02

The Loop

2.1 The circuit

Acceptance criteria are written first. A role-bound builder produces the artifact at a digest; a fresh, artifact-only critic judges it against the AC. NEEDS_EVIDENCE routes to a verifier that executes — never the builder — and binds evidence to a git SHA. APPROVED moves the artifact to a human promote gate. Every dispatch, verdict, and evidence record lands in the ledger.

2.2 Verdicts

  • APPROVED Verified, not plausible — critic approval plus non-builder evidence at a git SHA.
  • REVISE The critic flags; the builder fixes; nobody self-approves.
  • NEEDS_EVIDENCE Reading is not judging — render and runtime claims require execution output.
  • ESCALATE Round caps are circuit breakers — limits route to a human, never silent approval.
