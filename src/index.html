Agent Fleet

A minimal test bed for contract-driven agent orchestration.

v0 test run · T-001

  • Dispatch

    No work is dispatched before the ticket's Acceptance Criteria block is written. Every dispatch is appended to the fleet's event ledger.

  • Critique

    Builders never self-approve and the critic never fixes. Verdicts are APPROVED, REVISE, NEEDS_EVIDENCE, or ESCALATE — judged against the AC, not opinion.

  • Evidence

    APPROVED means verified, not plausible. User-visible artifacts need execution evidence recorded at a git SHA before they count as done.
